# AI Investment Radar — Free Edition

Web app personale di monitoraggio quantitativo dei mercati crypto, senza trading automatico.

## Attivazione

1. Repository **Settings → Pages → Build and deployment**: scegliere **Deploy from a branch**, **main**, **/(root)**, poi **Save**.
2. Repository **Actions → Public market scanner → Run workflow** per eseguire la prima scansione.
3. Aprire https://atarducci.github.io/ai-investment-radar/ dopo la pubblicazione.
4. GitHub Actions pianifica scansioni ogni due ore, senza garanzia di puntualità o continuità.

## Limitazioni

- I dati provengono da endpoint pubblici Binance, che potrebbero non essere raggiungibili.
- Lo score è euristico e non validato: non è una probabilità di profitto.
- Nessun ordine, nessun accesso ai conti, nessuna previsione Kronos.
- Il monitoraggio storico delle previsioni degli influencer non è ancora implementato.
- Il repository è pubblico: non inserire informazioni personali, posizioni finanziarie o credenziali.
